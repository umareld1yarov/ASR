# Звуки приложения ASR

Положите сюда файл звукового эффекта для смены активности.

- **Название файла**: `activity_switch.mp3` (или `.wav` / `.m4a`)
- **Путь**: `assets/sounds/activity_switch.mp3`

Этот файл автоматический подхватится сервисом `AudioService` при переключении активности во вкладке «Фокус».
